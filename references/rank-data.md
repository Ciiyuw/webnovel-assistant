# 榜单数据获取与比较

实际查询、导入、筛选、排序或比较历史榜单时读取。本 skill 提供工作规则，执行依赖宿主当前可用的工具与真实材料，不自带会员数据服务、全平台数据库或固定爬虫。

## 先确定范围与可用能力

从作者要求、已有作品定位和对话确定目的、平台、频段、分类、榜单、时间范围及需要多少样本。只有缺口影响工作时才问；作者已定平台就沿用。没有平台且作者在探索时可比较候选，不固定默认某个平台。

按当前来源实际提供的能力查询，不先承诺可取得首秀、增长、收藏、读者 UV 或任意历史日期。同名榜单也可能有不同的入榜门槛、分组和统计口径，先读榜单说明。

| 操作意图 | 执行要求 |
|---|---|
| top：某榜前 N | 按该榜实际名次取样，记录榜名、日期、筛选与可见范围 |
| list：详细列表/搜索/排序 | 仅使用来源支持的字段；排序结果注明是全榜还是已取得样本内 |
| categories / rank_names | 获取平台实际分类与榜名；有歧义时先核实名称，不能拼出一个不存在的榜 |
| dates | 查询来源或已有快照真正可用的日期，不从保留期推算每天都有数据 |
| count / stats | 区分总条数、页数、当前页数及样本统计；总量不可见时写明未知 |

这些是查询意图，不是本 skill 已注册的命令或 MCP 工具。环境里没有 `rank_data_query` 时不伪造工具调用；有真实工具/API 时按其文档执行，不把语义参数直接当成后端参数。

## 获取路由

先确认材料是否满足本次时间和范围要求，再选路径：

1. 作者提供的文件、榜单导出、旧快照和可读正文：核对来源、日期、完整性及格式。能回答本次问题就不重复抓取；历史材料不能冒充当前排名。
2. 作者已授权且实际可用的数据服务：核对文档、可用操作、字段及访问范围。凭据只供所需工具使用，不进入快照、报告或通用技能。
3. 平台公开榜单及作品页：使用可用搜索发现官方入口，读取榜单规则、筛选状态、作品链接与可见数据。搜索摘要、问答页、读者书单和作品粉丝榜不能替代平台作品榜。
4. 动态页面或文字提取不足：有可用浏览器时核对页面渲染、日期与筛选状态，再提取可见内容。遇到登录或安全校验停在该边界，改用公开范围或作者材料继续；不自行读取其他程序票据或安装绕过工具。

若使用 agent-reach 或其他获取技能，按其实际可用路由执行；没有该技能或后端时使用当前可用替代工具，不绑定固定 CLI、机器路径或接口。工具能调用、页面能打开、记录完整可用是三个不同状态。

获取非空结果后仍检查乱码、缺字、异常字形、缺失列和截断。必要时核对渲染页面或另一可核实来源。无法确认的书名或字段标注未核实，不猜字、不拿相似热门作品补位。阅读范围未核实时不直接开展正文分析。

## 日期、分页与指标

- 分开记录榜单数据日期、统计截止时间、采集时间及作品更新时间。时区未知时注明未知；缺少数据日期时不从采集时间反推。默认“最新”也应展示来源实际返回的日期。
- 日期只查实际可用范围；默认最新可能滞后，每日快照不能称为实时数据。只有搜索缓存时标记缓存日期与验证缺口。
- 获取全部记录时检查页码、每页条数、total、实际取得数量和重复行；支持分页才继续翻页。目的只需要少量样本时不无条件取全。只读一个 Top 页不声称覆盖全榜。
- 不同动作的响应可能有不同层级，先检查实际结构；HTTP 成功或有 JSON 外壳不等于有有效作品记录。截断 JSON 不当完整导入，找未截断来源或缩小获取范围。
- 排名数字小的通常在前，指标最高通常降序；以来源实际定义为准。“收藏最多”不能用不支持收藏排序的 Top 榜替代。
- 字段不存在时标记缺失，不填零，不悄悄替换指标。聚合新书数据不自动具备单日增长和连载状态；首秀增长不自动等于普通榜单的日增长。
- 保留原始展示值、单位和统计窗口。“1.2万”“10万+”等是近似或边界信息；即使换算单位也不能当作精确计数。标记 exact、rounded、lower_bound、range 或 missing 等实际精度状态。
- 起点月票、收藏、番茄在读、评分、UV 等不直接换算；日指标、累计指标和不同窗口的指标分别比较。

## 快照与证据记录

按作者要求保存到已有学习区；位置未约定时只补当前任务所需文件，不初始化整套数据库或目录。扫榜材料与小说事实分开，不写进技能包或每章上下文。

一次采集可以包含多个榜/页，但分组保持清楚。可用 Markdown、CSV 或 JSON，按任务选择；不要求作者手填完整表单。若任务需要重复比较，保留结构化记录和简短说明。建议最小字段：

| 层级 | 应记录的内容 |
|---|---|
| 范围 | 平台、榜名、频段、分类、筛选条件、入榜规则或尚未核实状态 |
| 来源 | 官方页面/授权服务/作者文件/搜索缓存等类型，URL 或文件位置 |
| 时间 | 数据日期、统计截止时间、采集时间、可得时区，缺失原因 |
| 覆盖 | 请求范围、已取得数量、已知总数或未知、页码/Top 范围、是否完整及缺口 |
| 样本 | 样本编号、字符串书籍 ID（可得时）、书名、作者、可见名次、字数、状态、作品链接、出处 |
| 指标 | 名称与口径、窗口/单位、原始值、可得数值或区间、精度状态、来源位置 |

保留书籍 ID 的字符串形式，避免长数字精度损失。标签可能是数组，也可能是内嵌 JSON 的字符串，先核对再解析。带签名的临时封面 URL 不作稳定的作品证据链接。

完整原始材料、规范化记录和给模型阅读的摘要分别保留；摘要引用原始位置，不重复保存整本正文。展示表只列当前分析需要的列，不能因展示缩略而丢失后续统计所需数据。作者手填、平台读取与 AI 推断分开，不用推断补成平台事实。

## 历史快照比较

先检查平台、榜单、频段、分类、筛选、统计窗口和指标定义是否一致。不可比的部分单列，来源改变时不直接相减。优先用同平台书籍 ID 对齐；无 ID 时用书名、作者、链接核对，名称变化待核实。不跨平台仅凭同名合并。

| 比较项 | 可以得出的结论与限制 |
|---|---|
| 名次 | 明确从第几到第几；名次改善不证明读者或收入增长 |
| 精确指标 | 前后有效且同口径时计算差值；增长率需基数有效且大于零 |
| 缺失、近似、阈值指标 | 保留缺口或精度限制，描述可支持的范围，不制造精确增长率 |
| Top N 集合变化 | 称进入/退出本次可见样本；全榜未覆盖时不能称首次上榜或全榜下榜 |
| 两个时点 | 描述该区间变化；连续趋势需要更多可比时点和足够覆盖 |

同一书可以在多个榜出现，做榜间比较时保留各榜记录，统计独立作品数时按可靠标识去重。小样本、不同作者基础、作品阶段和推荐背景带来选择偏差；结果不支持“某桥段导致成功”或收益保证。

## 交付与创作衔接

交付实际范围、数据日期、出处、样本及关键观察；历史比较注明前后覆盖和可比性，列出缺口。获取失败时说明哪些部分完成，并继续可核实的分析，不以熟悉作品填满表格。

分析回到 [扫榜与共同拆书](market-reading.md)：指标支持表现观察，书名/标签支持包装线索，简介支持阅读承诺，正文支持具体结构。作者实际感受与 AI 推断分别记录。没有正文时不把金手指、开局和爽点猜测写成已读结论。

按作者任务转为对标阅读清单、市场观察或原创方向；拟采用的机制仍是候选。持续监测、购买服务或发布内容需作者明确要求，普通扫榜不自动创建这些任务。
