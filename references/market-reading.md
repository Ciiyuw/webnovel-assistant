# 扫榜与共同拆书

## 扫榜取样

结合已有定位确定平台与题材；作者尚未决定平台时可比较候选，不先推翻已定方向。作者本轮只讨论流程时不开展实际扫榜。

使用平台真实榜单及可核实书页，记录平台、榜名/分类、榜单日期、采集日期、原始链接、可见排名、字数、连载状态、作者和指标口径。当前市场判断需要当前数据；搜索快照和历史榜单注明日期，不当作实时排名。

按目的组合新书样本与成熟作品：新书帮助观察近期切入点，成熟作品帮助观察长线兑现。规模、作者基础、推荐背景与指标口径不同时分别比较，不把起点月票、番茄在读或其他平台指标直接换算。

单本上榜提供线索，多本可比样本中的重复特征才支持趋势候选；排名不能证明某个具体桥段造成成功。记录样本不足、不可见指标和选择偏差，没有实际变化数据不声称趋势上升或下降。平台规则与签约要求另查官方来源，不沿用课程旧说法。

抓取失败时说明可取得的范围，继续分析有依据的部分；不能用熟悉的书名填满榜单。实际调用其他技能的采集脚本时先核对其版本、依赖和产物格式，本 skill 没有内置采集程序。

## 一起读与拆

从可读的正文选少量有差异的对标。作者先给阅读直觉时以此为讨论起点；作者还没读时 AI 可先给有出处的观察，不能代填作者感受。只知道书名、简介或评论时只能分析这些材料，不能冒充读过正文。

按实际阅读范围分层：先看开篇处境与看点，再追踪一个事件单元，必要时扩到阶段兑现；不为了完成八维度表单一次性读完整本。

| 观察项 | 要解释的问题 |
|---|---|
| 书名/简介承诺与兑现 | 包装承诺什么阅读体验，正文何时首次展示，后续靠哪些事件持续兑现？ |
| 开篇与核心看点 | 读者何时理解处境、开始期待什么？ |
| 章末期待 | 悬念由什么事件产生，后面怎样回应？ |
| 情绪变化 | 哪个行动或信息让读者紧张、释放、惊讶或牵挂？ |
| 因果与人物 | 谁作了什么选择，为什么，付出什么？ |
| 语言与场景 | 视角、对白、描写如何服务当时的阅读体验？ |
| 阶段兑现 | 铺垫怎样转化为收获、关系变化或认知变化？ |
| 成长与限制 | 能力、资源、代价怎样同时提供机会与阻力？ |
| 可迁移机制 | 更换人物与情境后，哪些结构功能仍成立？ |

每项给原文位置与依据，分开文本观察、AI 推断、作者感受和市场数据。不靠虚构追读或 AI 评分证明写法有效。

## 转为自己的想法

比较作品的共同点与差异，提炼结构功能、适用条件及代价，再用本书的人物、动机、规则和生活素材重新构思。可以学习“信息差怎样制造选择”，不能替换名字照搬情节链、标志性场景、设定或语言。

讨论输出围绕：哪些机制值得试、哪些与本书意图冲突、作者愿意长期写什么、还需读哪些章节验证。采用前都保留为候选，不因为参考作品成绩好就覆盖本书决定。

扫榜与拆书材料归学习区，本书已定与正文事实归作品档案。满意分析可以按作者要求保存；不自动向个人知识库写回或把整套对标材料复制进每章上下文。
