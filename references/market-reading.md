# 扫榜与共同拆书

## 按目的扫榜

结合已有定位确定平台与题材；作者尚未决定平台时可比较候选，不先推翻已定方向。作者本轮只讨论流程时不开展实际扫榜。

| 当前目的 | 取样与交付 |
|---|---|
| 找开书方向 | 同类近期新书，比较包装承诺、题材元素和可见表现，提出方向候选及待验证项 |
| 找对标 | 匹配题材与作品阶段，兼看新书和成熟作品，解释为何选它们而不只选榜首 |
| 看榜单变化 | 取得同口径真实快照，说明覆盖、名次/指标变化和进入/退出可见样本 |
| 搜书或作者 | 查询可用作品列表或书页，注明搜索范围和结果出处 |
| 拆开篇与剧情 | 从有差异的对标中选实际可读正文，按阅读范围分析事件与兑现 |

实际查询、导入或比较时读取 [榜单数据获取与比较](rank-data.md)，核对来源能力、日期、筛选条件与分页覆盖。按需使用 [扫榜观察单](../assets/templates/10-扫榜观察单.md) 保存范围和样本，不要求作者填写表单。

使用真实榜单及可核实书页；当前判断需要当前数据，历史材料注明日期。先展示实际取得的范围，再给观察；检索到入口不等于拿到完整榜单，样本内表现最高不等于全平台最高。

按目的组合新书样本与成熟作品：新书帮助观察近期切入点，成熟作品帮助观察长线兑现。规模、作者基础、推荐背景与指标口径不同时分别比较，不把起点月票、番茄在读或其他平台指标直接换算。

单本上榜提供线索，多本可比样本中的重复特征才支持样本内的方向观察；连续变化需要时间数据。排名不能证明某个具体桥段造成成功。记录样本不足、不可见指标和选择偏差；有意义时加入不同表现或写法的对照，避免只看成功作品，不为凑数量强制读大量书。平台规则与签约要求另查官方来源，不沿用课程旧说法。

获取失败、乱码或数据过期时说明实际日期与缺口，继续分析可核实部分；不能用熟悉的书名填满榜单。具体指标、完整记录和原始材料归数据层，给模型的摘要不能替代它们。

## 从样本形成市场观察

结论分开写：来源直接显示的事实、多个样本共有的特征、AI 对原因的推断、作者实际阅读感受。每个关键观察关联样本和证据，不用虚构追读、收入或 AI 评分证明写法有效。

书名/标签用于判断包装与题材线索，简介用于分析阅读承诺，正文用于解释实际开局、情绪和剧情兑现。榜单指标不证明某类读者为什么喜欢；没有正文时把金手指、开局或爽点结构保留为待读假设。

## 一起读与拆

从可读的正文选少量有差异的对标。作者先给阅读直觉时以此为讨论起点；作者还没读时 AI 可先给有出处的观察，不能代填作者感受。只知道书名、简介或评论时只能分析这些材料，不能冒充读过正文。

按实际阅读范围分层：先看开篇处境与看点，再追踪一个事件单元，必要时扩到阶段兑现；不为了完成八维度表单一次性读完整本。

| 观察项 | 要解释的问题 |
|---|---|
| 书名/简介承诺与兑现 | 包装承诺什么阅读体验，正文何时首次展示，后续靠哪些事件持续兑现？ |
| 开篇与核心看点 | 读者何时理解处境、开始期待什么？ |
| 章末期待 | 悬念由什么事件产生，后面怎样回应？ |
| 情绪变化 | 哪个行动或信息让读者紧张、释放、惊讶或牵挂？ |
| 因果与人物 | 谁作了什么选择，为什么，付出什么？ |
| 语言与场景 | 视角、对白、描写如何服务当时的阅读体验？ |
| 阶段兑现 | 铺垫怎样转化为收获、关系变化或认知变化？ |
| 成长与限制 | 能力、资源、代价怎样同时提供机会与阻力？ |
| 可迁移机制 | 更换人物与情境后，哪些结构功能仍成立？ |

每项给原文位置与依据，分开文本观察、AI 推断、作者感受和市场数据。不靠虚构追读或 AI 评分证明写法有效。

## 转为自己的想法

比较作品的共同点与差异，提炼结构功能、适用条件及代价，再用本书的人物、动机、规则和生活素材重新构思。可以学习“信息差怎样制造选择”，不能替换名字照搬情节链、标志性场景、设定或语言。

讨论输出围绕：哪些机制值得试、适用条件和长期事件来源是什么、差异化从哪里来、哪些与本书意图冲突、作者愿意长期写什么、还需读哪些章节验证。作者要求开书构思时，再把观察转成原创人物、目标、阻力和代价明确的候选；只要求扫榜时不自动写大纲或正文。采用前都保留为候选，不因为参考作品成绩好就覆盖本书决定。

扫榜与拆书材料归学习区，本书已定与正文事实归作品档案。满意分析可以按作者要求保存；不自动向个人知识库写回或把整套对标材料复制进每章上下文。
